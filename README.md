# Tic-Tac-Toe

A Tic-Tac-Toe game built using HTML, CSS, and JavaScript. The game supports both Local Multiplayer and AI modes.

## Features

* Play against another player locally.
* Play against an AI opponent.
* Three AI difficulty levels:

  * **Easy**: The AI plays the best move with 30% probability and a random move with 70% probability.
  * **Medium**: The AI plays the best move with 70% probability and a random move with 30% probability.
  * **Hard**: The AI always plays the best move using the Minimax algorithm.
* Responsive design for desktop and mobile devices.
* Animated X and O placement.
* Restart and Home buttons.
* Accurate win and draw detection.

## Gameplay

* In Local Mode, X and O take alternate turns.
* In AI Mode, the player always makes the first move.
